Step 1 — Create your Google Sheet

Go to sheets.google.com, create a new sheet. In Row 1 add exactly these 4 headers:

name   price   image   link

Step 2 — Make it public (read)

Click Share → Anyone with the link → Viewer. This lets your site read products without login.

Step 3 — Get your Spreadsheet ID

Copy the ID from your sheet's URL:
docs.google.com/spreadsheets/d/COPY_THIS_PART/edit

Step 4 — Get a free API Key

1. Go to console.cloud.google.com
2. Create a project → Enable Google Sheets API
3. Go to APIs & Services → Credentials → Create API Key
4. Restrict the key to Google Sheets API only (recommended)

Step 5 — Paste below & save

Your credentials are stored only in your browser (localStorage) and never sent anywhere except Google's own API.
